# ** HASIL IMPLEMENTASI LIST, SET, MAP PADA JFRAME**

## 1. LIST
List adalah struktur data yang digunakan untuk menyimpan kumpulan elemen secara berurutan. List mempertahankan urutan data sesuai saat elemen ditambahkan dan memperbolehkan adanya data yang sama (duplikat). Karena setiap elemen memiliki indeks, data dapat diakses berdasarkan posisinya dalam daftar. Pada program ini, List digunakan untuk menyimpan seluruh item yang ada pada JList tanpa menghilangkan data yang berulang.

## 2. SET 
Set adalah struktur data yang digunakan untuk menyimpan kumpulan elemen unik. Berbeda dengan List, Set tidak mengizinkan adanya elemen duplikat sehingga setiap nilai hanya dapat muncul satu kali. Ketika data yang sama ditambahkan lebih dari satu kali, Set hanya akan menyimpan satu salinannya. Pada program ini, Set digunakan untuk menunjukkan bagaimana struktur data dapat secara otomatis menghilangkan data yang berulang.

## 3. MAP
Map adalah struktur data yang menyimpan data dalam bentuk pasangan key-value. Setiap key harus bersifat unik, sedangkan value dapat memiliki nilai yang sama. Data pada Map diakses menggunakan key, bukan berdasarkan indeks seperti pada List. Pada program ini, setiap item disimpan sebagai value dengan nomor urut sebagai key, sehingga setiap data dapat diidentifikasi dan diambil kembali melalui key yang dimilikinya.
